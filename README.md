# 音乐用户听歌行为模拟数据集

## 数据集简介

数据通过程序模拟生成，不来源于真实音乐平台的用户日志。用户编号、歌曲编号及行为记录均为虚构，不包含真实用户身份信息或歌曲音频。公开分享的目的是便于学习者开展数据处理等研究工作。

## 文件与数据规模

数据文件为 `listening_logs.csv`，采用带BOM的UTF-8编码，逗号分隔，第一行为字段名。每行代表一次播放事件，而不是某名用户一天的汇总记录。

## 字段说明

| 字段 | 数据类型 | 含义 | 单位或取值 | 示例 |
| --- | --- | --- | --- | --- |
| `event_id` | 整数 | 播放事件的唯一编号，用于定位记录，不表示实际时间戳 | 无单位 | `1` |
| `user_id` | 字符串 | 虚拟用户编号；同一用户的多条记录使用相同编号 | `U0001`—`U1000` | `U0001` |
| `day` | 整数 | 事件发生在统一观察窗口中的第几天，不是具体日历日期，也不是该用户加入后的第几天 | 天，1—40 | `17` |
| `song_id` | 字符串 | 虚拟歌曲编号，前缀对应类型，后三位为该类型内的歌曲序号 | 无单位 | `G6_160` |
| `genre` | 字符串 | 此次播放歌曲所属的音乐类型 | 流行、摇滚、民谣、电子、古典、爵士 | `爵士` |
| `song_duration_seconds` | 整数 | 歌曲总时长；同一首歌曲的总时长固定 | 秒，150—300 | `282` |
| `listen_duration_seconds` | 整数 | 用户在本次播放事件中实际收听的时长 | 秒，不小于1且不超过歌曲总时长 | `253` |
| `favorite` | 整数 | 本次播放事件是否产生收藏标记 | 0表示未产生，1表示产生 | `0` |

需要注意：

- 一名用户一天可以有多次播放，也可以没有播放；每天的记录条数不固定。
- 同一用户可以重复播放同一首歌曲，因此不能仅凭 `user_id` 和 `song_id` 相同就删除记录。
  

## 数据示例

以下为数据文件的前三条记录：

```csv
event_id,user_id,day,song_id,genre,song_duration_seconds,listen_duration_seconds,favorite
1,U0001,17,G6_160,爵士,282,253,0
2,U0001,18,G6_196,爵士,181,151,1
3,U0001,18,G6_163,爵士,169,163,0
```

第一条记录表示：用户U0001在观察窗口第17天播放了一首爵士类歌曲，该歌曲总时长为282秒，本次收听253秒，没有产生收藏标记。第二、三条记录来自同一用户的同一天，但属于两次不同的播放事件。


## 数据质量

本版本检查结果：8个字段均无缺失值，`event_id`无重复，同一歌曲的类型和总时长一致，收听时长均在有效范围内，收藏标记仅取0或1。
